# Ola Ride Booking Analysis - Operational Insights

## Overview
This project focuses on analyzing Ola ride booking data to derive actionable insights that improve operational efficiency. The analysis highlights key factors influencing booking success, cancellations, revenue generation, and customer satisfaction.

## Tools & Technologies
- **SQL**: Used to address ad-hoc queries and extract key operational insights from booking data.
- **Power BI**: Used to create interactive visualizations, segmented into 5 areas:
  - Overall Analysis
  - Vehicle Type Analysis
  - Revenue Analysis
  - Cancellation Analysis
  - Rating Analysis

## Key Insights
- **Booking Success**: 62% of bookings are successful, leaving room for improvement.
- **Cancellation Trends**: 28% cancellation rate, mainly due to driver-related issues.
- **Revenue Insights**: Prime Sedans and Prime Plus vehicles generate the highest revenue.
- **Customer Demand**: Demand is the top reason for incomplete rides, followed by vehicle breakdowns.

## Recommendations
- Implement driver incentives to reduce cancellations and improve service.
- Optimize driver assignment logic, especially during peak hours.
- Focus promotions on high-revenue zones and vehicle types like Prime Sedans and Prime Plus.
- Encourage digital payments (UPI) to reduce cash handling and enhance efficiency.
